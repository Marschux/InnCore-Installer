# Installpunkt 8: Update

## Ziel

Das Installscript-Repository und optional die InnControl-Verwaltungsskripte aktualisieren.

## Ablauf

1. Das Verzeichnis des Installscript-Repositories ermitteln.
2. `git pull` im Repository ausführen.
3. Auswahl anzeigen:
   - Authserver-Verwaltungsskripte aktualisieren
   - Worldserver-Verwaltungsskripte aktualisieren
   - beide aktualisieren
   - überspringen
4. Je nach Auswahl den Ablauf aus `05-Authscript.md`, `06-Worldscripts.md` oder `07-Both-Scripts.md` ausführen.

## Ergebnis

- Das lokale Installscript-Repository ist aktualisiert.
- Optional sind die ausgewählten InnControl-Skripte aktualisiert.
